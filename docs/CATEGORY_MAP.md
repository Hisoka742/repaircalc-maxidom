# Карта «категория → виды работ» и сравнение с поэлементным матчером

Файл: `src/maxicalc/knowledge/category_work_map.csv` (по одной строке на каждую из **2 421**
категорий-листьев официального набора `products_final.json`; 88 790 товаров). Это **базовая линия**
(baseline), а не итоговая модель: каждому товару категории достаётся один и тот же набор работ.

## Как построена

1. **Поднятие дерева.** В файле у товара одна категория-лист и нет дерева. Дерево берём из YML-фида
   того же магазина (`scripts/build_category_lift.py` → `knowledge/category_lift.json`): 99,1 %
   товаров получают полный путь («Краска и малярный инструмент > Грунты, пропитки, олифы > Грунтовка»).
   Имя листа, встречающееся под несколькими родителями (90 имён), берёт родителя с наибольшим числом
   предложений в фиде.
2. **Черновик правилами** (`scripts/build_category_map.py`): только правила уровня категории из
   `work_rules.yaml` (без условий по названию товара).
3. **Ревью** (`knowledge/category_map_review.yaml`): для категорий, куда правила не попали, решение
   записано явно и с причиной; пустое множество («не вид работ») — тоже решение. Ревьюер: **LLM
   (черновик с помощью LLM)** — статус `reviewed-llm`. Людям нужно просмотреть строки `reviewed-llm` и
   `auto`, исправить спорные и поставить `reviewed-human` (такие строки пересборка не трогает).
4. **Охват.** 17 категорий (1 185 товаров) вне корней фида признаны ремонтными (карнизы, потолочные плинтусы и плитки,
   кухонные стеновые панели, «Ликвидация остатков» с розетками/дверями/плиткой) — `rescope` в файле ревью.

| статус | категорий | товаров |
|---|---|---|
| ремонт, виды работ заданы правилами (`auto`) | 678 | 37 491 |
| ремонт, виды работ заданы ревью (`reviewed-llm`) | 164 | 4 309 |
| ремонт, проверено: не вид работ (`reviewed-llm`, пусто) | 108 | 3 199 |
| не ремонт (сад, посуда, одежда, мебель, химия…) | 1 471 | 43 791 |

Не ремонт — **43 791 товар (49,3 %)**: для них правильный ответ «нет видов работ» (в разметке — группа
`negative`, в API — пустое множество, без очереди проверки).

## Матчер уровня товара и сравнение (PILOT, не люди)

Слой уточнений `knowledge/work_refine.yaml` (≈ 70 правил): в смешанных семействах (саморезы, дюбели,
монтажный клей, герметики, диски и пилки, профили, шпатели, валики и кисти, СИЗ, грунты по назначению)
**более конкретное правило заменяет категорийное** — по названию и параметрам товара, а не по слову
в категории. Модель (TF-IDF + логистическая регрессия) обучена на этих же метках как слабых и
**заполняет пробелы**: к найденному правилом она ничего не добавляет, только помечает расхождение для
проверки.

Золотого набора людей **ещё нет**, поэтому сравнение сделано на трёх **пилотных** наборах, размеченных
одним разметчиком — LLM, по определениям `docs/TAXONOMY.md`, без подсказок системы
(`eval/gold/pilot_llm_labels{,_b,_c}.csv`; метка *NOT human*). Разметчик же писал правила, поэтому
пилоты A и B (по ним правила доводились) завышают качество. Честные оценки — **первый прогон на
свежем наборе до доработки правил**:

| набор | первый прогон: baseline | первый прогон: матчер | на неоднозначных: baseline → матчер |
|---|---|---|---|
| A (100 неоднозначных + 110 «не ремонт») | 0,383 | 0,41 (правила ещё без уточнений) | 0,453 → 0,433 (**хуже**) |
| B (свежие 93 + 40) | 0,525 | 0,614 | 0,565 → 0,607 (+0,04) |
| C (свежие 89 + 30) | 0,628 | 0,685 | 0,550 → 0,623 (+0,07) |

После правок по ошибкам тех же наборов (**in-sample, не цитировать**): A 0,907, B 0,886, C 0,778
micro-F1; на неоднозначных строках A: 0,874 против 0,543 у baseline.

**Вывод для сцены:** на семействах, которых авторы правил ещё не видели, выигрыш над категорийной
картой скромный (+0,04…+0,07 micro-F1); после одного цикла «ошибки → правила для семейства» он
достигает +0,3. Это то самое «семантика, а не буквы»: каждое семейство требует знаний о применении,
а не слова в названии. Настоящее число даст только размеченный людьми набор (`eval/gold/worktype_annotator*.csv`).
Заметные спорные решения, которые должны принять люди: СИЗ (мы: `general_assembly`), универсальный
грунт (мы: приготовление под покраску, обои, плитку, шпаклёвку, штукатурку; не наливной пол), декоративные
П-образные профили (плитка и панели против крепежа).

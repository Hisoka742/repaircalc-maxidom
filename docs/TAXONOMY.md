# Таксономия видов работ

Источник правды: `src/maxicalc/knowledge/taxonomy.yaml` (раздел `work_types`) и правила
`src/maxicalc/knowledge/work_rules.yaml`. Этот файл строится скриптом
`scripts/make_taxonomy_doc.py`; список видов работ берётся из YAML.

## 1. Что размечаем

Для каждого товара каталога определяем **все виды ремонтных работ (процессы), в которых он
участвует**, и роль товара в каждом из них. Задача многометочная (multi-label): у товара может быть
от нуля до десятков видов работ. Типы помещений (`room_types`) и свойства (`properties`:
влагостойкий, моющийся...) остаются отдельными независимыми головами.

## 2. Роли товара

| роль | значение | примеры |
|---|---|---|
| материал (`m`) | входит в результат работы | краска, плитка, плиточный клей, кабель |
| инструмент (`t`) | используется исполнителем, не расходуется | валик, шпатель, плиткорез, дрель |
| расходник (`c`) | тратится в процессе или обслуживает его | малярная лента, шкурка, сверло, крестики, **грунтовка при покраске** |

Один товар может иметь разные роли в разных работах: грунтовка — материал в «Грунтовании» и
расходник в «Покраске стен», «Укладке плитки», «Поклейке обоев».

## 3. Правила включения

1. **Использование, а не слова.** Вид работы ставится, если товар реально применяется в этом
   процессе по инструкции производителя или общепринятой практике. Слова в названии не нужны и не
   достаточны («ламинат» в названии чистящего средства для ламината — это не укладка ламината).
2. **Все работы, где нужен.** Грунтовка получает грунтование, покраску стен и потолков,
   укладку плитки, поклейку обоев, шпаклевание, штукатурку. Стяжка и наливной пол — только если в
   карточке сказано «для пола», «универсальная» или «для оснований» (раздел 5).
3. **Инструмент и расходник наследуют работы своего основного применения.** Валик — покраска стен,
   покраска потолков, покраска дерева и металла, грунтование; малярная лента — те же покраски.
4. **Универсальный инструмент и крепёж** (рулетка, уровень, дрель, дюбели) получает
   `general_assembly` и 2–6 основных работ, где он критичен; не размечаем «всё подряд».
5. **Товар вне ремонта** (посуда, садовая техника, мебель, бытовая химия, удлинители, декор для
   ванной) получает **пустое множество**. Пустое множество — корректный ответ.
6. **Один товар — одна запись.** Упаковки и цвета одной позиции размечаются одинаково.

## 4. Спорные случаи

| случай | решение |
|---|---|
| гипсокартон и профиль | `drywall_install` и `ceiling_install` (профиль общий) |
| герметик санитарный | `sealing` (м); `plumbing_fixtures`, `tile_laying`, `window_install` — расходник |
| монтажная пена | `sealing`, `insulation`, расходник для `door_install`, `window_install`, `slopes` |
| плинтус напольный и потолочный, молдинг | `skirting_install`; карниз для штор — `cornice_install` |
| обои под покраску | `wallpapering` (м) и `wall_painting` (расходник-основа) |
| краска по металлу, эмаль, лак | `wood_metal_coating`, не `wall_painting` |
| краска для пола | `wood_metal_coating` |
| аэрозольная краска | `wood_metal_coating` |
| клей: универсальный, ПВА | `general_assembly` (расходник) и работы по названию; не `tile_laying` |
| плиточный клей и затирка | клей — `tile_laying`; затирка — `grouting` (не `tile_laying`) |
| крестики, СВП | `tile_laying` (расходник) |
| профили для плитки | уголки — `tile_laying` (м); закладки — расходник |
| декоративные профили (П-, Ш-, Т-, Н-образные), молдинги | `skirting_install` (раздел 5) |
| СИЗ: перчатки, очки, респираторы, каски | `ppe_consumables` (раздел 5) |
| светодиодная лента и блоки питания | `lighting_install` |
| лампочки | `lighting_install` (расходник); торшеры, настольные лампы, фонарики — вне ремонта |
| смеситель | `faucet_install`; гибкая подводка — расходник для `faucet_install` и `plumbing_fixtures` |
| душевая система | `plumbing_fixtures` и `faucet_install` |
| аксессуары ванной (мыльницы, полки) | вне ремонта (пустое множество) |
| дверная ручка, петли, замок | `door_install` |
| профили металлические «общие» | `general_assembly`, без привязки к отделке |
| кровля, водостоки, фундамент, забор | вне внутреннего ремонта (пустое множество) |
| набор «ремонт» без состава | по составу; если состава нет — передать на проверку |

## 5. Как проводить границы при разметке

- Сомневаетесь, есть ли работа, — спросите: «Исполнитель, делающий эту работу, возьмёт этот товар
  в руки (инструмент), потратит его (расходник) или установит/нанесёт (материал)?» Если нет — не ставьте.
- Не ставьте работу только из-за общей категории каталога («Метизы» — не значит всё сразу).
- Если для товара нужно больше 8 видов работ, проверьте: скорее всего это универсальный инструмент и
  нужно оставить основные 2–6 работ плюс `general_assembly`.
- Нечитаемое/пустое описание: ориентируйтесь на название и категорию; если и они не дают ответа,
  пометьте `none` и добавьте комментарий.

### Решения команды от 21.10.2026 (применяются в правилах и в разметке)

1. **СИЗ** (перчатки, очки, респираторы, каски, наколенники) — отдельный вид работ
   `ppe_consumables` «Общие работы: СИЗ и расходники». Это **не** метка каждой работы: рекомендатель
   добавляет СИЗ как сопутствующие товары (companions), а в разметке у товара только `ppe_consumables`.
2. **Универсальная грунтовка** относится к подготовке пола (`screed`, `self_leveling`) **только если в
   карточке написано** «для пола», «универсальная» или «для оснований»; иначе — только стены и
   потолки (грунтование, покраска, плитка, обои, шпаклёвка, штукатурка). Гидроизоляция — только если
   так сказано в тексте («гидроизоляция», «влагоизолятор»).
3. **Декоративные профили и молдинги** (П-, Ш-, Т-, Н-образные, угловые, потолочные плинтусы, галтели)
   — «Монтаж плинтусов и молдингов» (`skirting_install`). Карнизы для штор — `cornice_install`.

## 7. Формат разметки

Ячейка `work_types` в листе разметчика: id через `;`, `none` — ничего не подходит, `=` — принять предложение системы (только для строк с подсказкой). Правила разметки и метрики: `docs/EVAL_METHODOLOGY.md`.

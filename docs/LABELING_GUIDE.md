# Инструкция разметчику (1 страница)

**Задача.** Для каждого товара отметить **все виды ремонтных работ**, в которых он нужен: как
материал, инструмент или расходник. Если товар к ремонту не относится — «ничего не подходит».
Ваш лист: `eval/gold/worktype_annotatorN.csv` (258 строк). Цель — **не больше 1,5 часа**
(≈ 20 секунд на строку; по строкам с подсказкой — одно нажатие).

## Запуск (Windows, один раз)

```
cd E:\MAXIDOM_HACKATHON
.\.venv\Scripts\python.exe -m pip install streamlit
.\.venv\Scripts\streamlit.exe run scripts\label_worktypes_app.py -- eval\gold\worktype_annotator1.csv
```

Откроется браузер. Результат пишется в файл **после каждого клика**: закрыть вкладку можно в любой
момент, при повторном запуске вы продолжите с первой неразмеченной строки. Время на строку
пишется рядом (`*.timing.csv`). Готовый файл вернуть как есть.

## Клавиши

| клавиша | действие |
|---|---|
| **поле «Быстрый ввод кодов»**: `1c 3b`, Enter | отметить / снять виды работ по кодам (справа у каждого вида свой код и определение); `0` — ничего не подходит. Самый быстрый и надёжный способ |
| цифра этапа + буква на странице (например `3b`) | то же, одним нажатием (горячие клавиши работают, пока фокус не в поле ввода) |
| `Enter` | принять подсказку системы (только если она показана) |
| `0` | ничего не подходит (не ремонт или нет такого вида работ) |
| `→` или `n` / `←` или `p` | дальше / назад |
| `u` | не уверен (потом обсудим), `Esc` — сбросить набранный код |

## Правила (подробно — `docs/TAXONOMY.md`)

1. **По применению, а не по словам в названии.** Спросите: «исполнитель этой работы возьмёт товар в
   руки (инструмент), потратит (расходник) или нанесёт/установит (материал)?»
2. **Все работы, где нужен.** Универсальную грунтовку отмечаем под покраску, обои, плитку, шпаклёвку,
   штукатурку — но под стяжку и наливной пол **только если в карточке есть «для пола», «универсальная»
   или «для оснований»**.
3. **Универсальный инструмент и крепёж** — «Крепёж и общие монтажные работы» плюс 2–6 главных
   работ. Больше 8 отметок — почти всегда ошибка.
4. **СИЗ** (перчатки, очки, респираторы, каски) — только «Общие работы: СИЗ и расходники».
5. **Декоративные профили, молдинги, потолочные плинтусы** — «Монтаж плинтусов и молдингов»;
   карнизы для штор — «Монтаж карнизов».
6. **Не ремонт** (посуда, сад, мебель, одежда, бытовая химия, лампы-торшеры) — `0`.
7. Один товар — одна запись; цвет и фасовку не различаем.
8. Данные организаторов местами ошибочны (параметры от другого товара): ориентируйтесь на название и
   категорию; сомневаетесь — `u` и комментарий.

## Чего не делать

* Не советоваться по **первым 60 общим строкам** (под ними написано «Общая строка») — по
  ним считаем согласие разметчиков.
* Не искать ответ в других листах и не править таблицы правил: вы размечаете «глазами».
* Не торопиться «принимать подсказку» вслепую: подсказка — это ответ системы, и оценка её
  точности строится на ваших исправлениях.

После разметки: `python scripts/merge_worktype_gold.py` (согласие κ и α, золотой набор) и
`python scripts/eval_worktypes.py --gold eval/gold/worktype_gold.csv`.

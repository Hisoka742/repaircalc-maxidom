Пилотная разметка выполнена одним LLM-разметчиком, который писал и правила: числа PILOT завышены на
наборах, по которым правила дорабатывались (в таблице взяты только числа первого прогона на свежих
наборах). Независимую оценку даст только разметка людьми.

## 3. В работе

* Разметка золотого набора четырьмя участниками (≈ 1,5 ч на человека), согласие разметчиков (κ, α).
* ML-модель видов работ как основной движок: эмбеддинги + TF-IDF + атрибуты, калиброванные пороги,
  ансамбль с правилами; правила остаются признаком и запасным вариантом.
* Замер локальных LLM (Qwen3 4B, GigaChat 3.1 Lightning) как судьи серой зоны: точность на dev и задержка.
* Проверка людьми карты категорий (статус `reviewed-human`).

## 4. Риски

| риск | чем смягчаем |
|---|---|
| Разметка людьми не успеет до 7 ноября | инструкция, приложение с быстрым вводом, лист по 258 строк; без неё числа остаются PILOT, и мы так их и называем |
| Правила подогнаны под наши примеры | замороженный тест, журнал обращений, метрики первого прогона на свежих наборах |
| Данные организаторов содержат ошибки (параметры другого товара, пустой бренд, расход без единицы) | нормализация с хранением исходного текста, очередь проверки, отчёт по качеству |
| У части красок (фасадные, по металлу) нет расхода в карточке | умолчания только с источником; такие товары не попадают в расчёт комнаты |
| Нет сведений о заказах и рейтингах | веса рейтинга и маржи настраиваются и равны нулю; запас по раскладке — нормативный |
| Локальная LLM слабая на CPU | LLM вне горячего пути расчёта; без неё работают правила и шаблоны |

## 5. План до 7 ноября

1. Собрать разметку людьми, посчитать κ и α, пересчитать метрики; пересобрать подсказки в листах по
   актуальным правилам.
2. Выбрать модель привязки и судью серой зоны по dev; один раз прогнать замороженный тест и записать
   обращение.
3. Привязать выбранную модель к API с правилами как запасным вариантом; очередь проверки по серой зоне.
4. Добавить СИЗ и аксессуары в корзину как сопутствующие товары.
5. Подключить стенд организаторов, когда будет доступ; прогон «в день».
6. Дожать интерфейс и подготовить демонстрацию на ноутбуке: `make demo`.

## 7. Известные недостатки

* В `explain` значение 10 иногда печатается как `1E+1` (формат `Decimal`); на расчёт не влияет.
* Подсказки в листах разметки построены по более ранней версии правил и будут пересобраны.
* Видеофайлы главной страницы frontend (≈ 19 МБ) в репозиторий не включены: страница работает без них.
* Подбор для гостиной может предложить грунт-влагоизолятор: у категории «грунтовка» нет различения по
  назначению.
* Локальные LLM на этом ноутбуке не замерены: установка и загрузка моделей выполнены, прогон бенчмарка в плане.

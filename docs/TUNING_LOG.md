# Журнал настройки и защита от подгонки под тест

Правило: **тест нельзя использовать для настройки**. Правила, пороги и модель меняются только по
данным dev; по замороженному тесту изменения не делаются, а каждое обращение к нему записывается в
`docs/TEST_ACCESS_LOG.md` (скрипт `scripts/eval_frozen.py` сверяет SHA-256 набора и пишет строку).

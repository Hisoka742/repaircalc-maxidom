# Golden references from manufacturers' sheets

`tests/golden/golden_manufacturer.yaml` (generated by `scripts/make_golden_manufacturer.py`,
sheets via `scripts/fetch_references.py`): 64 cases, each with `source_url`, the quoted line and the
inputs. Expected values are plain Decimal arithmetic, independent of the engine.

| material | sheet | cases | verified |
|---|---|---|---|
| tile adhesive | Ceresit CM 11 PLUS | 8 | yes |
| grout | Ceresit CE 40 Aquastatic | 8 | yes |
| waterproofing | Ceresit CR 65 | 8 | yes |
| self-levelling screed | Ceresit CN 68 | 8 | yes |
| waterproofing mastic | Ceresit CL 51 | 8 | yes |
| primer | Ceresit CT 17 PROFI | 8 | yes |
| paint | Tikkurila Prof Euro 7 | 8 | yes |
| plaster | Knauf Rotband | 8 | **no**: footnote "*" of the 8,5 kg/m² line not extracted |

Totals: 56 manufacturer-verified, 8 unverified, 64 < the 80 asked for. Not covered, and why:
wallpaper roll calculators, laminate (Quick-Step/Tarkett) and Litokol: no machine-readable official
source was reachable; interactive manufacturer calculators cannot be run from here. These stay
"re-derived" (regression protection only) and are not to be quoted as verified.

## Where the engine disagreed with a manufacturer

1. **Adhesive table.** The engine's default table is the Ceresit CM 11 edition of 01.2020
   (1.7 / 2.0 / 2.7 / 3.6 / 4.2 / 5.5 kg/m²); the CM 11 PLUS sheet (2025-11-27) gives
   2.0 / 2.5 / 3.0 / 3.7 / 4.2 / 5.2. Both are the manufacturer's figures for different products.
   Fix: tables are selectable (`ADHESIVE_TABLES`), the service uses `cm11_plus` when the product
   name contains "CM 11 PLUS", otherwise `cm11`; the explain line names the table.
2. **Grout.** The formula with the default tile thickness (8 mm) and joint overestimates against
   CE 40's own table (10×10 cm, 2 mm: formula 0.512 kg/m² vs table 0.4). The table rows are now
   available (`tile.grout_table_kg`); the formula stays the fallback for tiles/joints not in the
   table, and is an estimate.
3. **Rotband** 8,5 kg/m² is quoted per the sheet's recommended 10 mm average layer, but the
   footnote was not readable (knauf.com returned 403): unverified.

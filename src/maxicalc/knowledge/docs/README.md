# Документы базы знаний (RAG)

Сюда кладут выдержки из технических листов производителей и норм (СНиП/СП): один файл на
источник. Формат: сначала строки `ключ: значение` (`source`, `calc`, `room`, `overlay`), затем
пустая строка и абзацы текста. Каждый абзац становится отдельным фрагментом базы знаний, а
`source` показывается покупателю как опора объяснения. Файл без `source` не загружается.
Не добавляйте то, чего нет в первоисточнике.
